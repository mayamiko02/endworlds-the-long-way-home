## How to read an entry

Each row summarises one manifest entry:

| ID | Title | Category | Status | File | Author/Source | Submitted | Notes |

- **ID** — `ELWH-<CAT>-<NNNN>`, unique, never reused.
- **Status** — one of: `proposed` → `in-review` → `changes-requested` → `approved` → `approved-master` (plus `rejected`, `deprecated`). Definitions live in the manifest's `status_lifecycle` block.
- **File** — primary file path relative to repo root; originals (PSD/KRA/WAV…) are listed in the manifest's `source_files`.
