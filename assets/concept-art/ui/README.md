# assets/concept-art/ui/ — UI concept art

## Purpose
Explorations for the game's interface: menus, HUD, headset travel interface, and especially the **Traveller's Journal** and Sanctuary management screens. UI must share the hand-painted art direction (ART_BIBLE.md) while staying readable.

## Contents
Currently empty — no assets registered. UI concepts become relevant in Phase 3–4 (see [ROADMAP.md](../../../ROADMAP.md)); early proposals still welcome.

## Naming
`<screen>_<descriptor>_vNN.png` — e.g. `journal_spread_v01.png`. Full rules: [../../NAMING_CONVENTIONS.md](../../NAMING_CONVENTIONS.md).

## Contributing
Branch `art/…`, manifest category `CON`, status `proposed`, PR per [../../ASSET_SUBMISSION_GUIDE.md](../../ASSET_SUBMISSION_GUIDE.md). Production UI ships from `assets/production/ui/`, not from here.

## Dependencies
