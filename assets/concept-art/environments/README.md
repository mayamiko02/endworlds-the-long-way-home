# assets/concept-art/environments/ — environment concept art

## Purpose
Mood keys, composition studies, palette scripts and parallax plans for the Endworlds and the Sanctuary. These define each world's painterly identity before any tileset is produced.

## Design intent (ART_BIBLE.md §3)
Hand-painted, composed, atmospheric; depth through layered value and light. Every world concept should include its palette script and intended parallax layer split (recorded in manifest `notes`).

## Contents
Currently empty — no assets registered. First expected submission: World 01 mood key + palette script (Phase 1 in [ROADMAP.md](../../../ROADMAP.md)).
