# assets/concept-art/characters/ — character concept art

## Purpose
Exploration and definition of the protagonist, alternate protagonists, NPCs and creatures: turnarounds, expression sheets, proportion/pivot sheets, palette swatches.

## Canon constraints (PROJECT_BIBLE.md)
- Protagonist: young Zambian man, ~19–23, consistent across every depiction; the first owner-approved reference set becomes `approved-master` and definitive.
- Alternate protagonists must remain visually traceable to the same person and consistent with established lore.
