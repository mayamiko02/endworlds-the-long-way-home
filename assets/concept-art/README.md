# assets/concept-art/ — concept & exploratory artwork

## Purpose
Painterly exploration: character studies, environment mood keys, palette scripts, UI explorations. Concept art is where we find the look before committing to production.

## Status contract
**Nothing in this folder is game-ready.** Concept files are never imported by the engine and never appear in builds. Promotion to production means creating new, spec-validated files under `assets/production/` — see [../ASSET_SUBMISSION_GUIDE.md](../ASSET_SUBMISSION_GUIDE.md).

## Contents
| Subdirectory | Holds |
|---|---|
| [characters/](characters/README.md) | Protagonist/alternate/creature/NPC studies, turnarounds, expression sheets |
| [environments/](environments/README.md) | World mood keys, palettes, composition studies |
| [ui/](ui/README.md) | Menu, HUD and journal layout explorations |

## Contributing
Follow [../ASSET_SUBMISSION_GUIDE.md](../ASSET_SUBMISSION_GUIDE.md) and [../NAMING_CONVENTIONS.md](../NAMING_CONVENTIONS.md); manifest category `CON`, status `proposed`. Quality/targets per [ART_BIBLE.md](../../ART_BIBLE.md).

## Dependencies
None. Do not add engine project references to files in this folder.
