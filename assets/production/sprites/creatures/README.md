# assets/production/sprites/creatures/ — creature & enemy sprites

## Purpose
Game-ready sprites for creatures, enemies and boss guardians (GDD §7.6).

## Prerequisites
The creature's approved concept must exist (manifest category `CON`, status `approved`) before production sprites are created. Boss designs are narratively gated — coordinate with PROJECT_BIBLE.md and the owner.

## Contents
Currently empty.

## Standards
- PNG, sRGB, clean alpha; consistent scale relative to the character set (ART_BIBLE.md §5).
- Document silhouette intent and any state variants (idle/aggro/damaged) in manifest `notes`.

## Naming & contributing
`<creature>_<state>.png` · manifest category `CRE` · see [assets/NAMING_CONVENTIONS.md](../../../NAMING_CONVENTIONS.md) and [assets/ASSET_SUBMISSION_GUIDE.md](../../../ASSET_SUBMISSION_GUIDE.md).

## Dependencies
Creature concepts from `assets/concept-art/characters/`.
