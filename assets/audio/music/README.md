# assets/audio/music/ — soundtrack

## Purpose
Original score: world themes, Sanctuary theme, boss music, emotional stingers. Music should carry the game's emotional identity (PROJECT_BIBLE.md themes) the way the painting carries its look.

## Contents
Currently empty — audio phase scheduled for Phase 6+ ([ROADMAP.md](../../../ROADMAP.md)).

## Standards (working defaults)
- WAV 48 kHz / 24-bit masters preserved; OGG Vorbis deliverables for in-game loops.
- Loop points seamless and declared (sample-accurate) in manifest `notes`.
- Zambian musical influences welcome where authentic and respectful — same rule as the art.

## Naming & contributing
`<scope>_<title>_vNN.wav|ogg` (e.g. `world01_theme_v01.ogg`) · manifest category `MUS` · [../../ASSET_SUBMISSION_GUIDE.md](../../ASSET_SUBMISSION_GUIDE.md). Disclose composition tools and any samples; sample libraries need licence proof.

## Dependencies
None.
