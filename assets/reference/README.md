# assets/reference/ — owner-supplied reference material

## Purpose
Reference material for contributors and agents: the approved character reference once it exists, inspirational images, cultural reference, real-world photos the owner wants designs anchored to. This is what the repository was originally created to hold.

## Contract
- **Reference is not production.** Files in this folder never ship in the game and are marked category `REF` in the manifest.
- Only the **project owner** adds canonical creative references here (especially anything defining the protagonist's appearance). Contributors may propose references via PR.
- Personal or private material does not belong in a git repository — the owner controls what enters this folder.
