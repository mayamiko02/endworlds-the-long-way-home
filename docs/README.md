# docs/ — extended documentation

## Purpose
Home for documentation that supports the core root-level documents ([README.md](../README.md) index) without bloating them. If a guide is long, role-specific or procedural rather than canonical, it lives here.

## Contents
| Path | Purpose |
|---|---|
| [roles/](roles/README.md) | Specialised instructions per contributor role (artists, character designers, environment designers, gameplay programmers, QA agents) |

## What does NOT live here
- Canon story/lore → [PROJECT_BIBLE.md](../PROJECT_BIBLE.md) (root)
- Gameplay design → [GAME_DESIGN_DOCUMENT.md](../GAME_DESIGN_DOCUMENT.md) (root)
- Asset pipeline docs → [assets/](../assets/README.md)

## Naming conventions
Guides use `UPPER_SNAKE_CASE.md` at this level; directories use `lowercase-with-hyphens`.

## Contributing
Add new guides through the normal branch + PR flow ([CONTRIBUTING.md](../CONTRIBUTING.md)). A new guide must be listed in the table above **in the same PR** (continuous documentation, AGENTS.md rule 9).

## Dependencies
None — Markdown only. Keep links relative so they work on GitHub and in clones.
