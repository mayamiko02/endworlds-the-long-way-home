# ARTIST GUIDE
### Role instructions for contributing artists and art agents

Read first, in order: [AGENTS.md](../../AGENTS.md) → [ART_BIBLE.md](../../ART_BIBLE.md) → [assets/ASSET_SUBMISSION_GUIDE.md](../../assets/ASSET_SUBMISSION_GUIDE.md). Then return here.

---

## Mission
Produce artwork that looks **hand-painted, cinematic and intentional** — oil-paint texture, visible brushwork, atmospheric depth. An ENDWORLDS image should be identifiable as ENDWORLDS at a glance.

## Hard rules (from the master instructions)
1. The protagonist's appearance is fixed; use the **approved character reference** as the definitive source. If none exists yet, you are doing **concept exploration only** — label it accordingly.
2. Never produce: generic AI aesthetics, plastic/3D-looking pieces, inconsistent anatomy or proportions.
3. Zambian identity: authentic, respectful, through character and cultural context — never stereotypes.
4. Concept ≠ production. Keep the folders honest ([assets/README.md](../../assets/README.md)).
5. Never overwrite an `approved-master` asset without explicit owner authorisation — submit a new version instead.

## Workflow
1. Check `assets/ASSET_INDEX.md` and the manifest for existing/related work — extend, don't duplicate (rule 1).
2. Create a branch: `art/<short-description>`.
3. Produce work at the quality bar in ART_BIBLE.md §1; save source files (PSD/KRA/Aseprite) — originals are preserved (rule 6).
4. File + name per [assets/NAMING_CONVENTIONS.md](../../assets/NAMING_CONVENTIONS.md); request the next ID in the category.
5. Add the manifest entry with status `proposed`, honest `author_or_source`, and technique notes (brush set, palette script, references used — disclose tools honestly).
6. Open the PR; describe intent, what is final vs. exploratory, and what was validated (dimensions, alpha, pivot consistency where relevant).

## Quality gates art must pass before `approved`
- [ ] Reads as hand-painted and art-directed (not filtered or auto-generated in feel)
- [ ] Consistent with related approved assets (character, palette, lighting)
- [ ] For production: meets ART_BIBLE.md §5 specs (format, alpha, pivots, dimensions)
- [ ] Manifest entry complete and truthful

## Out of scope
Canon decisions, palette ratification, and rejection of others' approved work — owner calls all three. Proposals are welcome and must be labelled **PROPOSAL**.
