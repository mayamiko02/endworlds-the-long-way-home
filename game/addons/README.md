# game/addons/ — third-party Godot plugins (INTENTIONALLY EMPTY)

## Purpose
Reserved location for Godot editor/runtime plugins.

## Policy (AGENTS.md rule 5)
**Default: zero addons.** Do not introduce unnecessary dependencies or expensive technical complexity. Any addon must be justified in its PR: what it saves, its licence, its maintenance state, and why built-in Godot 4 functionality is insufficient. Owner sign-off required.

## Contents
Empty — and staying that way unless a justified exception is approved.

## Contributing
If proposing an addon, vendor it here, pin the version, record source + licence in the PR description.

## Dependencies
None.
